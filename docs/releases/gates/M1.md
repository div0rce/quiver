## 9. PRD ambiguities

None blocking. One under-specification handled by the ambiguity policy:

- **REQ-DISP-007 state inventory vs REQ-DISP-005 read-once.** REQ-DISP-007 fixes dispatch state as "exactly" four items (entry table, policy epoch, override slot, feature mask), but REQ-DISP-005's read-`QUIVER_ISA`-exactly-once mandate requires caching the parsed value somewhere. Implemented as a fifth `constinit` atomic (`g_env_cap`), documented in-source. **Proposed smallest PRD amendment:** extend the REQ-DISP-007 inventory with "one `std::atomic<std::int8_t>` environment-cap slot, populated together with the feature mask." No behavioral latitude was taken: read-once semantics, case-sensitivity, and ignore-rules follow REQ-DISP-005 exactly.
