## 7. Checks deferred (with reasons)

1. **"PMU counters collected on a Linux runner (values sane: cycles > 0, IPC ∈ (0.1, 8))"** — GitHub-hosted runners are virtualized and expose no PMU; `perf_event_open` fails and the REQ-BENCH-005 **degrade path is what CI exercises** (output marked `pmu: unavailable`). Real-PMU evidence (sane cycles/IPC) lands with the first registered bare-metal Linux ledger machine at M5 and will be recorded in that gate. The wrapper's Linux code path compiles in every ubuntu CI job.
2. **Cross-platform golden-hash identity** — asserted by this PR's CI on x86-64/ARM64/macOS (the M2 acceptance criterion); local evidence is ARM64+macOS only.
